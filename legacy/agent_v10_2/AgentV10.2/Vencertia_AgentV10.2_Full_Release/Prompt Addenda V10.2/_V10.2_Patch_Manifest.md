# AgentV10.2 User Knowledge Runtime — Additive Prompt Patch Manifest

## Purpose

Add `Vencertia User Knowledge Runtime V1.0` to AgentV10.1 without deleting or rewriting any existing Prompt body.

## Patch method

Each patch file is a standalone appendix. Deployment means **append the corresponding appendix after the existing AgentV10.1 integration material in a copy/new V10.2 release**, leaving the AgentV10.1 source DOCX unchanged.

## Targeted prompts

1. `Memory Write.docx`
2. `Pydantic  JSON Schema.docx`
3. `Routing.docx`
4. `Vencertia Orchestrator .docx`
5. `Vencertia Financial & Business Model.docx`

All other 10 Specialist prompts require no User Knowledge Runtime patch at this release.

## Canonical non-changes

- `MemoryRecord` remains the canonical durable personalized knowledge object.
- `FounderProfile` remains the canonical current Founder profile domain object.
- Project KB, Evidence, Assumption, Experiment, Action, Decision and Financial Snapshot remain separate canonical domains.
- No `KnowledgeRecord`, `KnowledgeType`, `KnowledgeStatus`, or `knowledge_records` canonical store is introduced.
- MemoryType enum values remain unchanged.
- MemoryStatus remains `ACTIVE|SUPERSEDED|CONFLICTED|REJECTED|EXPIRED|ARCHIVED`.
- Memory SourceType values remain unchanged.
- Company Intelligence Runtime V1.1, its 24 JSON Schemas and Company Case Schema V1.4 remain untouched.

## V10.2 precedence

The appended V10.2 section is authoritative only for User Knowledge Runtime integration and explicitly listed consistency corrections. All non-conflicting AgentV10.1 rules remain in force.

## One consistency correction

`Pydantic  JSON Schema.docx` section 43 describes Monetization Distance meanings 1–4 while stating valid values 1–3. V10.2 defines the valid range as **1, 2, 3, 4**, matching the four documented meanings. No meaning is renamed.
