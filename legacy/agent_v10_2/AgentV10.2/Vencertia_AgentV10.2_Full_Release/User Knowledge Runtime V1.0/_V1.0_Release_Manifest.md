# Vencertia User Knowledge Runtime V1.0 — Release Manifest

## Compatibility

- Target: AgentV10.1 Full Release.
- Migration style: additive / zero-loss.
- Original 15 Prompt DOCX files: untouched.
- Company Intelligence Runtime V1.1: untouched.
- Company Case Schema V1.4: untouched.

## Runtime additions

- AgentV10.1-aligned Memory Pydantic contracts.
- Stable Memory write manager with conservative WRITE/MERGE/SUPERSEDE/CONFLICT/REJECT handling.
- Idempotent in-memory repository for deterministic tests.
- PostgreSQL canonical Memory schema.
- Separate Memory permission metadata.
- Memory retrieval policy with tenant/project/status/privacy filters.
- A0–A10 Context Builder policy.
- UserKnowledgeProjection read model.
- FounderProfile refresh signaling without creating a duplicate profile store.
- JSON Schema generation.
- Zero-conflict compatibility audit.

## Prompt patches

Standalone appendices for exactly five Prompt files:

- Memory Write
- Pydantic / JSON Schema
- Routing
- Vencertia Orchestrator
- Vencertia Financial & Business Model

No other Specialist Prompt is changed by this release.

## Explicit removals from the prior experimental User Knowledge Base V1 design

- Removed `KnowledgeRecord` as canonical entity.
- Removed `knowledge_records` table.
- Removed new top-level `GOAL`, `FOUNDER_FIT`, `ANTI_PATTERN` MemoryType values.
- Reused AgentV10.1 MemoryStatus including `REJECTED`.
- Reused AgentV10.1 Memory SourceType names.

## Validation targets

- Pydantic/JSON Schema generation.
- deterministic tests.
- zero-conflict audit.
- additive patch DOCX rendering QA.
